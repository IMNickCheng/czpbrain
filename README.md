# 个人 AI 第二大脑仓库

> 本仓库是【你的姓名】的跨模型、跨设备个人知识档案库。  
> 所有内容均为纯 Markdown 文本，任何 AI 模型均可直读直写，无需任何额外接口。

## 使用说明（AI 与人类通用）

1. 首次接触本仓库，请先依次阅读以下文件：
   - `01-身份档案/profile.md` —— 我的身份与背景
   - `03-Agent工作规范/AGENT_GUIDE.md` —— 你（AI）的工作规范
2. 日常任务中，根据需求读取 `02-经验知识库/INDEX.md` 定位知识。
3. 任何 AI 读写本仓库后，请在 `04-版本日志/entries/` 追加一条当日记录，并更新 `04-版本日志/CHANGELOG.md`。
