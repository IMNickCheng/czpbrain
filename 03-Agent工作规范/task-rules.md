# 任务执行规则

## 一、任务开始前
1. 复述任务目标，确认理解无误。
2. 若目标不明确，先提问澄清，不盲目开工。

## 二、任务进行中
1. 复杂任务拆解为步骤，逐步推进。
2. 关键节点同步进展，避免黑箱操作。

## 三、任务完成后
1. 交付成果并说明存放位置。
2. 若有新经验，按规范沉淀到知识库。

## 四、通用原则
- 先做对，再做好；先可用，再优化。
