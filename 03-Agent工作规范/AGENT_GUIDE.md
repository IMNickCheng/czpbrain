# Agent 工作规范（你 = 读本仓库的 AI）

> 本文件是你在操作本仓库时的唯一行为准则，优先级最高。

## 一、访问流程（每次操作必做）
1. 先读本文件。
2. 需要身份信息时，读 `01-身份档案/profile.md`。
3. 需要知识时，读 `02-经验知识库/INDEX.md` 定位。
4. 输出前参考 `writing-style.md`。

## 二、写入规范
1. **先看再写**：写入前先读取目标文件，避免覆盖。
2. **时间戳留痕**：每次写入/修改后，追加一条版本日志（见第四节）。
3. **不删除**：禁止删除任何已有内容，只允许追加或覆盖标注。
4. **单文件单主题**：新知识新建独立文件，不堆砌到一个文件。

## 三、输出规范
- 遵循 `03-Agent工作规范/writing-style.md` 的风格。
- 长内容拆分，保持单文件简洁。

## 四、版本日志记录（每次操作必做）
完成任意写入后，执行：
- 新建 `04-版本日志/entries/YYYY-MM-DD-序号.md`
- 内容格式参考 `04-版本日志/entries/示例.md`

## 五、安全边界
- 不写入身份证号、银行卡、密码等敏感信息（参见 `safety-rules.md`）。
- 不对外传播本仓库内非公开信息。
